# AI 협업 운영 방식

## 역할
- 사용자: 최종 결정자, 범위 승인자, PR 병합자
- ChatGPT: 기획·요구사항·설계·작업지시·독립 검토
- Antigravity 무료: 코드베이스 조사, 구현, 테스트, 브랜치/PR 작성
- Claude Free: 중요한 변경에 대한 독립 리뷰어
- GitHub: 문서·코드·이슈·PR의 단일 기준 저장소

## 표준 순서
1. ChatGPT가 현재 저장소 기준으로 작업 범위와 수용 조건을 작성한다.
2. Antigravity가 먼저 읽기 전용으로 관련 코드·문서·테스트를 조사한다.
3. 조사 결과와 구현 계획을 사용자에게 제시한다.
4. 승인 후 별도 브랜치에서 구현하고 테스트한다.
5. Antigravity가 변경 파일, diff 요약, 테스트 결과, 잔여 위험을 보고한다.
6. Claude가 diff와 테스트를 독립 검토한다.
7. Antigravity가 리뷰 지적을 반영하고 재테스트한다.
8. ChatGPT가 프로젝트 목적·아키텍처·정책 정합성을 확인한다.
9. 사용자가 GitHub PR을 검토하고 직접 병합한다.

## Antigravity 첫 세션
첫 세션은 조사만 한다. 파일 수정, 브랜치 생성, 커밋, push, PR 생성 금지.
확인 대상:
- README.md, REPORT.md, AGENTS.md(없으면 없다고 기록)
- `.github/workflows/`
- `config/`
- `radar/`
- `scripts/`
- `tests/`
- `data/`의 구조와 품질 상태
- 최신 커밋 5개 및 미병합 PR
- 실제 실행된 GitHub Actions 결과(확인 가능한 경우)

## 작업 등급
- 낮음: 문서 오탈자, 표시 문구, 단순 UI. 테스트 범위가 작으면 Claude 리뷰 생략 가능
- 중간: 추출 규칙, 표시 규칙, 설정, RSS 피드 추가/비활성화. Claude 리뷰 권장
- 높음: 수집 파이프라인, 데이터 스키마, 일일 파일 저장, 품질 판정, 별칭 병합, 스케줄, 외부 API, 보안/정책. Claude 리뷰 필수

## 금지 사항
- `main` 직접 수정·push
- 사용자 승인 없는 피드 추가/삭제
- 과거 데이터 파일 삭제·재생성
- API 키/PAT를 코드나 로그에 입력
- fixture 통과를 실제 외부 사이트 검증으로 표현
- 계획 문서만 보고 구현 완료라고 표현
- YouTube API 정책 검토 없이 통계 집계·파생 점수 구현
