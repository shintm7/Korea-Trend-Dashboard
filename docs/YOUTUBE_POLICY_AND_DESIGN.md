# YouTube 활용 — 정책 우선 설계 메모

상태: 설계 검토 전. 구현 승인 아님.

## 목표
YouTube를 단순 링크 모음보다 더 유용한 근거 채널로 쓰되, 무료 운영과 API 정책 준수를 우선한다. 뉴스/RSS와 다른 종류의 관심 신호를 제공하는 것이 목적이다.

## 중요한 정책 제약
YouTube API Services Developer Policies의 일반 규칙은 다음과 같다.
- API Data를 임의로 집계하는 것은 제한된다. 예외는 YouTube가 인정한 동일 콘텐츠 소유자 채널 데이터 등 매우 제한적이다.
- API Data로 자체 파생 데이터나 지표를 만드는 것도 일반적으로 금지된다.
- 일반 비인증 데이터는 필요한 기간 동안 임시 저장할 수 있으나 30일을 넘기지 않아야 하며, 이후 갱신 또는 삭제해야 한다.
- 조회수 등 통계는 데이터 유형별로 저장 조건이 다르다. 비인증 통계의 장기 보관을 허용한다고 가정하지 않는다.
- 파생 지표 및 통계 장기 보관의 추가 허용은 2026-06-01 이후 별도 심사·승인을 받은 분석 개발자에 대한 정책 예외다. 본 프로젝트가 해당 승인을 받았다고 가정하지 않는다.
- YouTube 웹사이트 스크래핑, 비공식 API, 비인가 데이터 수집은 사용하지 않는다.

공식 문서:
- https://developers.google.com/youtube/terms/developer-policies
- https://developers.google.com/youtube/terms/revision-history
- https://developers.google.com/youtube/data/determine_quota_cost
- https://developers.google.com/youtube/data/reference/rest/v3/search/list

## 현재 프로젝트에 대한 영향
다음은 기본 설계에서 제외한다.
- 여러 채널의 조회수/좋아요/댓글 합산
- 영상별 조회수 증가율을 계산해 트렌드 성장 점수화
- 채널 다양성·반응률을 API 데이터에서 계산해 자체 점수화
- 영상 제목/설명에서 자동 키워드 추출 후 API 데이터 기반 신규 트렌드 후보 생성
- API 응답 원문/통계를 무기한 누적 보관

이전 기획의 'YouTube 영상 제목에서 후보를 발굴하고 조회수 증가 속도로 확산을 판정'하는 아이디어는 정책 검토 결과, 일반 API 권한만으로 구현 가능한 것으로 간주하면 안 된다.

## 안전한 기본 방향
1. RSS 등 별도 허용 데이터원에서 후보 키워드를 만든다.
2. 후보 키워드를 이용해 YouTube Data API에서 관련 영상을 검색할 수 있는지 정책 검토한다.
3. 허용되는 경우 영상별 원본 정보와 YouTube 링크/임베드를 표시한다. 영상 통계를 조합한 자체 점수는 만들지 않는다.
4. API 응답 데이터는 정책상 허용된 보관 기간과 갱신/삭제 규칙을 구현한다.
5. 화면에는 API에서 가져온 YouTube 정보와 프로젝트 자체 분석을 명확히 구분한다.
6. YouTube를 독립 후보 발굴원으로 쓰고 싶다면, 자동 API 데이터 가공을 전제로 하지 말고 YouTube가 제공하는 공식 제품/기능과 허용된 이용 방식을 별도로 조사한다. 사람의 수동 큐레이션이 필요한 경우 자동화 범위와 수작업 범위를 분리한다.

## 무료 할당량
공식 기본 할당량 안내 기준:
- `search.list`: 별도 하루 100회 호출 버킷, 호출당 1단위
- 기타 일반 API 메서드: 합산 하루 10,000단위 기본 할당량
- 추가 페이지 요청은 각각 별도 호출로 계산
- 실제 할당량은 Google Cloud Console의 해당 프로젝트 설정에서 확인

따라서 API 사용이 승인되더라도 광범위한 키워드 검색을 매시간 반복하지 않는다. 검색 빈도·쿼리 수·페이지 수를 먼저 예산화한다.

## 구현 전 필수 확인
- API Data가 프로젝트의 구체적 목적에 사용될 수 있는지
- 제목/채널명/통계 각각의 저장·표시·갱신·삭제 규칙
- 검색 결과의 표시 요건과 YouTube 링크/임베드 요구사항
- 비인증 데이터의 30일 제한 및 통계 데이터의 별도 규칙
- 파생 지표 금지 및 별도 심사 예외의 적용 가능성
- 무료 할당량에 맞는 일일 호출 예산
- API 키를 GitHub Actions Secrets로 보관하는 방법

정책상 불확실성이 남으면 기능 구현을 중단하고 공식 문서 또는 YouTube API Services 팀의 안내를 확인한다.
